大型語言模型 (LLM) 基礎概念與提示詞工程

大型語言模型（Large Language Models, LLMs）是建立在深度學習架構上的自然語言處理模型。本篇筆記整理自 LLM Wiki，涵蓋了語言模型的核心運作原理，以及如何透過提示詞（Prompt）有效地與模型互動。

1. LLM 的核心運作原理

LLM 的本質是一個「文字接龍」機器。當給定一段上下文時，模型會計算詞彙庫中每一個字詞作為「下一個字」出現的機率分佈，並挑選機率最高（或透過採樣策略挑選）的字詞輸出。

  • Transformer 架構：目前主流的 LLM 皆基於 Transformer 架構，其核心機制「注意力機制 (Attention Mechanism)」能讓模型在處理當前字詞時，關注句子中其他相關的字詞，從而理解長文本的脈絡。
  • 預訓練 (Pre-training)：在海量無標籤的文本數據上進行訓練，學習人類語言的語法、常識與邏輯。
  • 微調 (Fine-tuning)：在特定任務的標註數據上進一步訓練，使其能夠遵循人類指令（如 InstructGPT）或具備特定領域知識。

2. 提示詞工程 (Prompt Engineering)

提示詞工程是引導 LLM 產出預期結果的一門技術。一個好的提示詞可以大幅減少模型的幻覺（Hallucination），提高輸出的精確度。

  • 給予清晰的脈絡 (Context)：避免使用模糊的指令，應明確告知模型它的「角色」與「背景」。
  • 少樣本提示 (Few-Shot Prompting)：在提示詞中提供 1 到 3 個優良的輸入/輸出範例，讓模型參考範例的格式與邏輯進行回答。
  • 思維鏈 (Chain of Thought, CoT)：在指令中加入「請一步一步思考 (Let's think step by step)」，強迫模型展開推理過程，特別適用於數學或邏輯問題。

提示詞範例對比：

❌ 糟糕的提示詞：
幫我寫一篇關於蘋果的文章。

✅ 優秀的提示詞：
你是一位專業的營養學家。請撰寫一篇約 300 字的短文，介紹「蘋果」對人體健康的 3 大好處。
文章請使用親切、專業的語氣，並以重點條列的方式呈現。

3. 總結

理解 LLM 的運作限制與 Transformer 的注意力機制，是寫出優質提示詞的基礎。未來的 AI 應用開發（如 Vibe Coding），將越來越依賴開發者將複雜的系統邏輯轉譯為結構化且精準的自然語言提示詞。
