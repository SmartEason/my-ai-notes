機器學習核心觀念複習與專題規劃

本篇筆記整理了機器學習第 1 至 7 章的核心觀念，並附帶期末專題的規劃方向建議，適合作為快速複習與實作參考。

Chapter 1: 機器學習簡介 (ML Introduction)

  • 機器學習的三大類型：監督式學習（Supervised learning）、非監督式學習（Unsupervised learning）與強化學習（Reinforcement learning）。
  • 監督式學習的兩大任務：分類（Classification）用於預測離散的類別標籤（如垃圾郵件分類）；迴歸（Regression）用於預測連續數值結果（如學生成績）。
  • 非監督式學習：處理沒有標籤的資料，主要任務如分群（Cluster analysis），讓群內的物件具有高度相似性。
  • 機器學習標準流程：包含資料預處理（特徵萃取、縮放）、學習（模型選擇、交叉驗證）、評估（效能指標）與預測新資料。

Chapter 2: 訓練機器學習分類器 (Training ML Algorithms)

  • 感知機 (Perceptron)：用於二元分類，透過計算特徵與權重的內積，搭配步階函數（Step function）輸出預測類別。
  • 收斂條件：感知機只有在資料為「線性可分（Linearly separable）」且學習率夠小的情況下才能保證收斂。
  • 自適應線性神經元 (Adaline)：使用連續的線性啟動函數與損失函數（如 SSE），並透過「梯度下降法（Gradient Descent）」來更新權重。
  • 梯度下降的變體：
    • 批次梯度下降 (Batch GD)：用完整訓練集更新一次權重，計算成本高。
    • 隨機梯度下降 (SGD)：對每一筆樣本增量更新權重，收斂速度快，適合大數據與線上學習。
    • 小批次學習 (Mini-batch)：折衷方案，每次使用一小批樣本進行更新。

Chapter 3: Scikit-learn 分類器之旅

  • 邏輯斯迴歸 (Logistic Regression)：用於分類任務，透過 Sigmoid 函數輸出樣本屬於某類別的「機率」，適合處理線性不可分的問題。
  • 過度擬合 (Overfitting) 與 偏差-變異 (Bias-Variance)：
    • 過度擬合：模型過於複雜，導致在訓練集表現好，但泛化到測試集表現差，屬於「高變異（High variance）」。
    • 修正方式 (正規化 Regularization)：可加入 L2 正規化（透過參數 C 或 λ 控制），C 值越小，正規化強度越強，會使特徵權重縮小以防止過擬合。
  • 支援向量機 (SVM)：優化目標是「最大化邊界（Maximize the margin）」，找出距離決策邊界最近的訓練樣本（支援向量）並最大化其距離，以此降低泛化誤差。
    • 非線性分類 (Kernel Trick)：利用核函數（如 RBF/高斯核函數）將資料映射到高維度空間，使其變為線性可分。
  • K-近鄰演算法 (KNN)：屬於非參數（Non-parametric）與基於實例的學習，直接尋找距離最近的 K 個鄰居進行多數決，無需訓練模型參數。

Chapter 4: 資料預處理 (Data Preprocessing)

  • 特徵縮放 (Feature Scaling)：
    • 正規化 (Normalization)：通常指將特徵縮放到 [0, 1] 的區間 (Min-max scaling)。
    • 標準化 (Standardization)：將特徵轉換為平均值為 0、標準差為 1 的常態分佈形式，更容易讓權重初始化為 0 的演算法進行學習。
  • L1 正規化與特徵選擇：相較於 L2，L1 會產生「稀疏解（Sparse solutions）」，使得多數不重要特徵的權重變為 0，可作為特徵選擇技術，適合高維度資料。

Chapter 5: 降維技術 (Dimensionality Reduction)

  • 主成分分析 (PCA)：是一種「非監督式」演算法，透過尋找資料「最大變異」的方向（特徵向量）來建立新的特徵子空間，主要用於資料壓縮與視覺化。
  • 線性鑑別分析 (LDA)：是一種「監督式」演算法，目標是尋找能「最大化類別間可分性」的特徵軸，計算時會使用到類別間與類別內的散佈矩陣。
  • 非線性降維 (t-SNE)：針對非線性問題可使用 t-SNE 等流形學習技術來進行資料降維與視覺化。

Chapter 6: 模型評估與超參數調校

  • K折交叉驗證 (K-fold Cross-validation)：將訓練集分成 K 等份，輪流驗證。不平衡資料建議使用「分層 K 折 (Stratified k-fold)」以保留各類別比例。
  • 學習曲線 (Learning curves)：透過繪製準確率與訓練樣本數的關係，可用來診斷模型是否面臨高偏差（Underfitting）或高變異（Overfitting）。
  • 評估指標 (Metrics)：
    • 混淆矩陣 (Confusion Matrix)：視覺化呈現 TP、TN、FP、FN。
    • 對於不平衡資料需使用 Precision（精確率）、Recall（召回率/TPR）與 F1-score。
    • ROC 曲線與 AUC：繪製 FPR 與 TPR 的關係，並計算曲線下面積（AUC）來評估整體效能。

Chapter 7: 總體學習分類器 (Ensemble Classifiers)

  • 總體學習概念：結合多個基底分類器的預測結果，透過多數決機制產生比單一模型更精確且強健的結果。
  • Bagging (裝袋法)：透過「重抽樣法 (取後放回)」抽取隨機樣本訓練分類器（如隨機森林），能有效降低模型變異數。
  • Boosting (提升法)：後續的分類器會專注於學習前一個分類器分類錯誤的樣本。
    • AdaBoost：根據預測錯誤調整樣本權重。
    • Gradient Boosting (梯度提升)：不修改樣本權重，而是讓下一棵樹擬合前一棵樹產生的「偽殘差 (Pseudo-residuals)」。

期末專題規劃方向建議

基於 1-7 章觀念的開發藍圖 (Roadmap) 作為專題大綱：

  1. 定義問題與資料收集 (Ch1)
    • 明確定義專題是「分類問題」(預測類別) 還是「迴歸問題」(預測數值)。
    • 資料來源：可參考課程使用的 UCI Machine Learning Repository。
  2. 資料預處理與特徵工程 (Ch4 & Ch5)
    • 說明將如何處理缺失值，以及如何將類別特徵編碼。
    • 切割訓練集與測試集 (如 80/20)，並套用標準化 (Standardization)。
    • 若特徵過多，提出將使用 PCA 進行非監督降維，或使用 L1 正規化/隨機森林進行特徵選擇。
  3. 模型選擇與訓練 (Ch3 & Ch7)
    • 規劃使用多種模型進行比較基準 (Baseline)，例如：Logistic Regression、SVM、KNN。
    • 為了提升表現，重點應用「總體學習 (Ensemble)」演算法，如 Random Forest 或 XGBoost (Gradient Boosting)，獲得更好的泛化能力。
  4. 模型評估與超參數調校 (Ch6)
    • 說明將使用 K-fold Cross-validation 來取得無偏差的效能估計。
    • 規劃使用 Grid Search 找出最佳的超參數 (如 SVM 的 C 值與 Kernel 選擇)。
    • 最終成果展示：繪製混淆矩陣、ROC曲線，並計算 F1-score 等指標（特別針對不平衡資料）。
